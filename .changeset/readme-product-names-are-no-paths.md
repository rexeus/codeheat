Keep a README sentence that names products with a dot and a slash. "Shared UI components for React/Next.js apps." and "A TypeScript/Node.js client for the billing API." are descriptions: a word whose every segment starts with a capital letter is no file path, and "Run time checks for the data model." is no instruction. A path with a lower case folder, such as `src/Client.js`, still is one.
