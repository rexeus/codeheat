Link the treemap to the territories. The Map section groups its tiles by the territory that holds each file (the default; "Folders" keeps the old grouping), at a detail you pick, with the recommended one marked and the number of territories at each. A tile of the fit map and a "Show in the map" button on each place to start fill the map with that territory alone, under a bar that names it and offers "Show all territories"; selecting a file elsewhere zooms back out. The color modes, filter, and side panel work as before, and a report from an older codeheat without territories groups by folder as it did.
