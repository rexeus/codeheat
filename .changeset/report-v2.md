Report v2. (Placeholder: the bump is pending the owner's decision; until then this changeset collects the changes of the v2 release.)

- Heat a file only for the changes that are counted. A logical change of more than `thresholds.maxCommitFiles` (50) files already said nothing about coupling, cohesion, or a territory's `changes`; it now adds nothing to a file's `changes` (`FileStats.changes`, `ContractFile.changes`) and so nothing to its heat (`changes × (loc + complexity.total)`) either. Heat shares, the verdict's `leakShare`, coupling degrees, co-change probabilities, and the hub and unstable-interface gates now rest on the same changes as a territory's `changes` and `fit.containment`, so a sweeping refactor no longer heats the files it touched.
- Name the repository, not the work tree folder. `repository.name` is the folder of the repository's main work tree, also when `codeheat` runs in a linked work tree (`git worktree add`), or the name of a bare repository without `.git`; it was the folder the analysis ran in.
- Name sibling folders that change together with a brace glob. A `group` territory's `path` is `packages/a/{x,y}` (`{x,y}` at the root) instead of `packages/a/x + packages/a/y`, and so is every sentence that names it: a territory's `splitReason`, the entry points' `verdict` and `designMove`, the terminal, and the HTML report.
- Judge the trend on the territories the verdict judges. `verdict` gains `trend` (`eroding`, `improving`, `holding`, or `unknown`): per quarter of the series, how much of the judged territories' changes stayed inside, pooled over them, read with the robust line and the gate of `erosion.verdict`, and `unknown` with fewer than `thresholds.minVerdictWindows` (5) quarters of at least `thresholds.minWindowChanges` changes. An eroding `trend`, no longer the modules' `erosion.verdict`, lowers the verdict's level one step, and the HTML report's arrow beside the verdict shows it. `erosion` is unchanged.
- Count the files the universe leaves out as generated. `totals` gains `generated`: the tracked files named like code or a contract (and not removed by `--exclude`) that the universe leaves out because they lie below a generated or vendored directory (`dist`, `build`, `vendor`, …), are minified by name (`.min.`), are marked `linguist-generated` or `linguist-vendored`, or cannot be read as unminified text.
