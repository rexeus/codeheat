Report v2. (Placeholder: the bump is pending the owner's decision; until then this changeset collects the changes of the v2 release.)

- Heat a file only for the changes that are counted. A logical change of more than `thresholds.maxCommitFiles` (50) files already said nothing about coupling, cohesion, or a territory's `changes`; it now adds nothing to a file's `changes` (`FileStats.changes`, `ContractFile.changes`) and so nothing to its heat (`changes × (loc + complexity.total)`) either. Heat shares, the verdict's `leakShare`, coupling degrees, co-change probabilities, and the hub and unstable-interface gates now rest on the same changes as a territory's `changes` and `fit.containment`, so a sweeping refactor no longer heats the files it touched.
- Name the repository, not the linked work tree. In a linked work tree (`git worktree add`), `repository.name` is the folder that holds the repository's `.git`, or the name of a bare repository without `.git` (the folder that holds it, for a hidden one such as `proj/.bare`); it was the folder of the linked work tree. Any other work tree, and every work tree of a repository whose git directory lies elsewhere (`--separate-git-dir`), keeps the name of its folder.
- Name sibling folders that change together with a brace glob. A `group` territory's `path` is `packages/a/{x,y}` (`{x,y}` at the root) instead of `packages/a/x + packages/a/y` (a backslash escapes `\`, `,`, `{`, and `}` in a folder's name inside the braces), and so is every sentence that names it: a territory's `splitReason`, the entry points' `verdict` and `designMove`, the terminal, and the HTML report.
- Judge the trend on the territories the verdict judges. `verdict` gains `trend` (`eroding`, `improving`, `holding`, or `unknown`): per quarter of the series, the share of the changes touching a judged territory that touched no other territory, read with the robust line and the gate of `erosion.verdict`, and `unknown` with fewer than `thresholds.minVerdictWindows` (5) quarters of at least `thresholds.minWindowChanges` changes. An eroding `trend`, no longer the modules' `erosion.verdict`, lowers the verdict's level one step, the HTML report's arrow beside the verdict shows it, and the terminal's "Over time" section states it, with the modules' erosion after it as context. `erosion` is unchanged.
- Count the files the universe leaves out as generated. `totals` gains `generated`: the tracked files named like code or a contract (and not removed by `--exclude`) that the universe leaves out because they lie below a generated or vendored directory (`dist`, `build`, `vendor`, …), are minified by name (`.min.`), are marked `linguist-generated` or `linguist-vendored`, or have content that is binary, minified, or larger than 1 MiB.
- Print the answer above the analysis. The terminal's `analyze` view begins with one sentence that answers whether the design holds up to the way the code changes: the verdict's level, its trend, the percent of the change effort that sits in areas that leak, and why the evidence is thin when it is (`Under strain, getting worse: 65% of the change effort sits in areas that leak, judged on only 45 changes.`); without a level, why there is none. The evidence is thin without a level, with fewer than `thresholds.thinBelowChanges` (100) counted changes, with fewer than `thresholds.thinBelowAreas` (3) judged territories, or in a shallow clone; `thresholds` gains both limits. The line that counts the territories at the recommended detail says `Areas:` instead of `Territories:`.
- Leave test code out of every design measure. A test file (by name or directory, as before) is no part of any change: before anything is measured, every change loses its test files, is sized by the files that remain (so `thresholds.maxCommitFiles` counts code, not tests), and a commit of nothing but test code joins no change (it neither counts against the 30 commits of a pull request nor splits one). Test code has no heat, coupling, module, territory, or area, is never a hotspot or a place to start, and counts in no `files`, `changes`, or heat share; `files` and `totals.files` hold the other code only. `testCode` lists the test files with the counted changes their commits belong to (`totals.testCode` counts them; `--limit` cuts the list like `files`), a commit of test code alone is no real commit (`window.realCommits`), so a window of nothing but test commits is quiet, and `inspect` on a test file answers "test code, not judged" with those changes (`testCode` in `inspect --json`) instead of a ranked entry.
- Drop the placement of tests in territories. With test code out of every measure, no territory holds tests: the `tests` territory kind and `Territory.testFiles` are gone, a territory's `files`, `changes`, and `heatShare` are those of its code, and the terminal's `inspect` no longer prints a "test code of" line.
- Drop the test flags that no measure needs any more. `FileStats.test`, `Coupling.testPair` (and an `inspect` partner's `testPair`), `Module.testOnly`, `CopyFamily.testOnly`, and `TerritoryClique.codeHeatShare` are gone, and an entry point's evidence names the heat at stake `heatShare` where it said `codeHeatShare`: with test code out of every measure, all the heat is the code's. The terminal no longer marks a partner as `(test)` or counts families of test code, and the HTML report drops the "Include test code" switch of its top hotspots.
- Judge a directory's loose files as an area. When a directory splits into its folders, its own files (those directly in it and those of folders too small to be territories) are a territory of the new kind `files`, named after the directory, and a real area: counted among the territories of the recommended detail, judged, listed in `areas[]` with `stays`, a partner to leak into, and a place to start. Only a bucket of smaller folders (`other`) stays unjudged and goes to `basis.rest`; the loose files are never part of a bucket any more, and the bucket's `description` no longer names their files. A library with a flat `src/`, such as Effect's `packages/effect/src`, is judged instead of leaving most of its heat unjudged.
