# codeheat

Find where complexity and change frequency meet in a git repository — and which files keep changing together.

```bash
npx codeheat analyze            # top hotspots in the terminal
npx codeheat analyze --html     # treemap in the browser
npx codeheat analyze --json     # ranked report for agents
npx codeheat inspect <file>     # what to know before editing a file
```
